# 马国戡乱史：狮鹫尼亚重置

#### 介绍
本项目为游戏钢铁雄心4马国戡乱史（Equestria at War）mod的submod。

#### 使用说明
可自行搜索mod使用教程。

#### 编写说明（写前必看！！！！）
1.一般的文件名开头使用REP_FAT_，防止错误覆盖原版文件，以及与覆盖原版文件相区分（原版文件即mod马国戡乱史的文件）。
2.如果要覆盖原版文件，请在修改了原版的内容后自行加上注释“#修改”，以便后续原版更新时方便直接“Ctrl+C”、“Ctrl+V”。
3.在写国策代码时，每条国策必须要用#注释国策中文名，并且国策名必须与策划案上一致！国策icon统一为“GFX_goal_[id]”，[id]处即填写对应国策的id。
4.国策图标的图片文件命名必须要与策划案上一一对应、完全一致！
